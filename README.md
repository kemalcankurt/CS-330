# 3D Scene Final Project
This project is a 3D scene recreation featuring a guitar, a mug of coffee, a notebook, and pens on a wooden table. It was built using OpenGL and GLM, focusing on textures, lighting, and scene organization to create a natural, inviting environment.

## How I Approach Designing Software
When designing software, I focus first on breaking the problem into smaller pieces. I think about the objects, their interactions, and the final goal of the program. I use modular design early on, so each part is reusable and easy to maintain.

## New Design Skills Learned
While working on this 3D project, I improved my skills in scene composition and texture mapping. I also got better at balancing visual realism with performance, especially when dealing with multiple light sources and object materials.

## Design Process Followed
<li> Research and Planning: Looked at a real-world reference photo.</li>

<li>Object Selection: Broke the scene into basic shapes. </li>

<li> Modular Development: Wrote reusable functions for transformations, textures, and materials. </li>

<li> Lighting and Texture Work: Focused on making the materials look natural. </li>

<li> Testing and Adjustments: Constantly tested lighting angles, scaling, and object placement. </li>

## Applying Tactics to Future Work
The modular design tactics I used (like custom transformation functions and texture loaders) can easily be applied to future 3D projects, UI/UX designs, or even larger software systems. Keeping the code organized from the start saves a lot of time during revisions.

## How I Approach Developing Programs
I start small, build something basic that works, and then iterate. I test early and often, adding one feature at a time rather than trying to build everything at once. I also try to think about scalability and readability even in small projects.

## New Development Strategies Used
<li> Custom Lighting Configurations: Used multiple light sources for realism. </li>

<li> Texture Management: Created a flexible texture loading system. </li>

<li> Camera and Navigation Planning: Focused on viewpoint control even without an advanced camera system. </li>

<li> Debugging Step-by-Step: Handled scaling, rotation, and placement issues through small, targeted fixes. </li>

## Importance of Iteration
Iteration was a huge part of this project. Each time I adjusted an object's scale, position, or lighting, I immediately reviewed the scene and refined it. The final scene is the result of many small improvements over time.

## How My Development Approach Evolved
At the start of the course, I would jump into coding quickly. Over time, I learned to plan first, code second. I also learned the importance of modularity by writing reusable functions early, I saved myself from a lot of rework later in the project.
